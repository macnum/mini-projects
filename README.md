# Mini-projects

## Css animation practice

> ### Projects

1. **Card Flip** — 3D card flip using rotateY and backface-visibility
2. **3D Cube** — Spinning cube using preserve-3d and chained transforms
3. **Navbar** — Sliding underline effect using pseudo elements and scaleX
4. **Loading Spinner** — CSS only spinner with ripple pulse effect
5. **Toast Notification** — Slide in notification with progress bar and JS class toggling
6. **Dropdown Menu** — Expanding dropdown with scaleY bounce animation

### What I was practicing

- transform (translate, scale, rotate, skew)
- transition timing and easing
- @keyframes and animation properties
- transform-origin and preserve-3d
- Combining CSS animation with JavaScript class toggling

### Built with

HTML, CSS, vanilla JavaScript
